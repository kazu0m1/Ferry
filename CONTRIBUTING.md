# Contributing to Ferry

Thanks for your interest in Ferry.

For the first public release, the simplest contribution path is:

1. Search existing Issues before opening a new one.
2. For bugs, include Windows version, Ferry version, reproduction steps, expected behavior, and actual behavior.
3. For performance or crash reports, enable Ferry debug logging only while reproducing the problem and attach only logs you are comfortable sharing.
4. Do not include private file contents, credentials, personal paths, or other sensitive information in public Issues.

Pull requests are welcome. Please keep changes aligned with Ferry's scope philosophy: reuse Windows capabilities where practical and avoid introducing large private subsystems for functionality the OS already provides.
