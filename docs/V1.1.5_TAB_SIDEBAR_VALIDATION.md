# Ferry v1.1.5 Tab / Sidebar Windows Validation

**Date:** 2026-09-20  
**Baseline:** Ferry v1.1.4 + v1.1.5 candidate changes  
**Result:** PASS

## Candidate build

- Windows GitHub Actions `Build.cmd`: PASS.
- Candidate artifact was produced successfully before final release promotion.
- Tab drag uses the private `Ferry.TabItem` data format; normal file D&D formats are unchanged.

## Real-machine checks

- [x] Three open tabs can be reordered left/right by mouse drag.
- [x] The tab `×` button closes normally and does not accidentally start reordering.

## Scope

The v1.1.5 change is limited to tab ordering and Sidebar folder context-menu interaction. No application behavior changes were made to Shell Copy/Move, Ferry-to-Ferry file D&D, external Explorer D&D completion, removable-drive lifecycle, Paste-result selection, archive work, or the v1.1 selection engine during final promotion.
