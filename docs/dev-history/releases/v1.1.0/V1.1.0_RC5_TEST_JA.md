# Ferry v1.1.0 RC5 — 実機確認項目

**基準:** v1.1.0 RC4 までの主要機能は確認済み  
**目的:** RC4で発生した「Breadcrumb表示時にpath文字列が見えなくなる」回帰の修正確認。全回帰のやり直しは不要。

---

## A. 最重要 — Breadcrumb表示

1. Ferry起動直後のBreadcrumbを確認する。
2. 通常の階層を数段移動する。
3. `Ctrl+L` → Location Box → `Esc`でBreadcrumbへ戻す。
4. 同じ操作を数回繰り返す。

期待:
- [ ] Breadcrumbの文字列/crumb buttonが正常に見える。
- [ ] Toolbar/path領域の高さはLocation Box表示時と同じで変化しない。
- [ ] `Ctrl+L` → `Esc`後もBreadcrumbが正常に再表示される。
- [ ] 各crumbをクリックして親階層へ移動できる。

## B. 狭いWindow / 深いpath

Window幅を狭めるか、長い階層pathを表示する。

期待:
- [ ] Breadcrumb文字列がScrollbarによって縦方向に消えない。
- [ ] horizontal scrollbar自体は表示されない。
- [ ] pathが幅を超える場合は、現在位置側（右端側）のcrumbが見える。
- [ ] Toolbarの高さは変わらない。

## C. RC3/RC4最小回帰

- [ ] `Ctrl+L` → List/Grid mouse操作でBreadcrumbへ戻る。
- [ ] `Ctrl+L` → EscでBreadcrumbへ戻る。
- [ ] Selection Anchorのgray `1,1`破線が従来どおり。
- [ ] Rubber-band autoscroll speed設定が30〜300のまま。
- [ ] Sidebar境界double-click auto-fitが正常。
- [ ] List通常rubber-bandが正常。
- [ ] Grid通常rubber-bandが正常。
