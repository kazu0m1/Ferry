## Scope

RC12はkeyboard-navigation jumpの原因採取用diagnostic build。RC11に対して修正ロジックは追加せず、状態ログのみ追加する。

## Source inspection

### `Program.cs`
- RC12 diagnosticでは`Logger.Configure(true)`として常時ログを有効化。
- production finalへは持ち込まない。

### `MainWindow.cs`
- titleを`Ferry - RC 12 diagnostic`へ更新。
- true-background plain-click経路へ`[RC12_NAV]` diagnostic snapshotsを追加。
- Up/Down `PreviewKeyDown`前とDispatcher `ContextIdle`後のsnapshotを追加。
- Snapshot内容: focus、selection、Ferry anchor、WPF private AnchorItem / LastActionItem、CollectionView current。
- RC11 `RestoreSelectorItemFocusWithoutSelection`は変更なし。
- rubber-band semantics / D&D / autoscroll / List↔Grid syncに変更なし。
