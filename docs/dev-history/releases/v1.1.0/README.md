# Ferry v1.1.0 development release history

This directory preserves the release-candidate records created while Ferry v1.1.0 was being finalized.

The files here are **historical development records**, not the current release documentation.

- `RELEASE_NOTES_v1.1.0-rc*.md` — RC-specific release notes.
- `RC*_MANIFEST_JA.md` — RC composition / change manifests.
- `V1.1.0_RC*_STATIC_VALIDATION.md` — static validation records from the preparation environment.
- `V1.1.0_RC*_TEST_JA.md` — Windows real-machine checklists used during RC validation.

Current v1.1.0 release documents remain at the repository root:

- `RELEASE_NOTES_v1.1.0.md`
- `Ferry_SPEC_v1.1.md`
- `FINAL_RELEASE_CHECKLIST_JA.md`
- `FINAL_RELEASE_STATIC_VALIDATION.md`
- `PUBLIC_RELEASE_AUDIT.md`

The production selection baseline and prototype history are archived separately under `docs/dev-history/rubber-band/`.
