# Ferry v1.1.0 RC20 — 実機確認

対象: `1.1.0-rc20`  
目的: RC19で残った **左10px gutterのheader部分だけ他カラムと色が異なる** 視覚差を解消し、RC19でPASSした挙動を維持していることを確認する。

RC20のアプリケーションロジック変更は **gutter headerの明示背景色削除のみ**。selection / hit testing / keyboard / rubber-band / D&Dは変更しない。

## 0. ビルド・起動
1. `Build.cmd` を実行する。
2. `Portable\Ferry.exe` を起動する。
3. Window title が **Ferry - RC 20** であること。

## 1. 最重要 — gutter headerの色
1. List表示にする。
2. 左10px gutterのheader部分を見る。
3. **gutter headerがName等の他のcolumn headerと同じ背景色・theme表現**になっていること。
4. gutterだけ灰色/白色など別色の縦帯に見えないこと。

## 2. RC19選択表示の確認
1. 任意の行Aを選択する。
2. 青いselection fillが左gutterへ入らず、最右データカラム右端までで止まること。
3. 破線Selection Anchorも同じdata-column spanに収まること。
4. 左gutterと右側tailがtrue backgroundのまま見えること。

## 3. 最小回帰
以下を各1回だけ確認する。
- 左gutterクリック → selection clear。
- 右側true backgroundクリック → selection clear。
- 左gutterまたは右tailからrubber-band開始。
- `A → 空白 → ↓ = B`。
- `A → 空白 → Shift+↓ = A/B`。
- Gridで `← → ↑ ↓` が正常。
- 選択済みitemからfile D&Dが正常。

## PASS条件 / 仕様凍結条件
- Section 1〜3がすべてPASS。
- とくにgutter headerが他data-column headerと同色・同themeになっている。
- 新しい回帰がない。

すべてPASSなら、RC20のUI/selection仕様を **v1.1.0 finalの凍結基準** とする。以降はrelease metadata / documentation / packaging以外のアプリケーション挙動を変更しない。
