# Ferry v1.1.0 RC15 — Static Validation

**Candidate:** `1.1.0-rc15`  
**Environment limitation:** Windows / .NET Framework 4.8 runtime build is not available in the assistant environment. Validation below is static only.

## Scope

RC15 changes only keyboard navigation synchronization around Up/Down and Shift+Up/Down:

1. RC13 empty-selection Arrow recovery remains.
2. Empty-selection `Shift+Up` / `Shift+Down` now uses the preserved keyboard origin and creates an anchored range.
3. Ordinary unmodified Up/Down is still handled by WPF, then Ferry synchronizes `KeyboardNavigationItem`, `SelectionAnchorItem`, and WPF extended-selection anchor to the resulting focused item.
4. Rubber-band, D&D, autoscroll, Breadcrumb, Sidebar and archive logic are not intentionally changed.

- Repeated Shift+Arrow extends/shrinks from A.

- Grid navigation remains natural.
- Existing Shift+Click, rubber-band and D&D behavior remains intact.
