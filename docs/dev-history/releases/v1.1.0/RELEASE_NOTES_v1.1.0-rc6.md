# Ferry v1.1.0 RC6 Release Notes

RC6 is a focused Breadcrumb layout correction on top of RC5.

## Changed

- Restored the Breadcrumb horizontal scrollbar (`Auto`).
- Increased the fixed path-row height to reserve both the Location Box height and one Windows horizontal-scrollbar row.
- Long Breadcrumbs can therefore keep their scrollbar visible without squeezing the crumb text out of view.
- Toolbar/path height remains constant when switching between Breadcrumb and `Ctrl+L` Location Box.

No intentional changes were made to selection, rubber-band, autoscroll settings, Sidebar auto-fit, Location Box dismissal, or file operations.
