# Ferry v1.1.0 RC11 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc11`  
**Baseline:** cleaned v1.1.0 final candidate

## Scope

RC11 changes only the stationary plain true-background focus/current recovery path. This environment has no Windows/.NET Framework 4.8 WPF compiler/runtime, so Windows rendering and keyboard behavior require the accompanying real-machine checklist.

## Source inspection

### `Source/Ferry/MainWindow.cs`

- Window title changed to `Ferry - RC 11`.
- Added `RubberBandBackgroundFocusItem` to the per-tab pending rubber-band state.
- Plain true-background MouseDown records the currently focused item before Ferry focuses the Selector.
- The existing immediate selection clear and pending rubber-band route remain intact.
- MouseUp captures the recorded item before `EndRubberBandGesture` resets pending state.
- Focus restoration runs only when:
  - the gesture did not become an active rubber-band,
  - start item is true background (`null`), and
  - modifiers are none.
- `GetFocusedSelectorItem` only returns a `FileItem` belonging to the active selector.
- `RestoreSelectorItemFocusWithoutSelection` only focuses an already-realized container and intentionally does not call `ScrollIntoView`.
- A defensive post-focus clear preserves the true-background contract of zero visible selection.
- Begin/end gesture reset the new transient field.
