# Ferry v1.1.0 RC19 — 実機確認

対象: `1.1.0-rc19`  
目的: RC18で成立した **Listの左10px true-background gutter / 最右カラム右側のtrue background / rubber-band / keyboard navigation** を維持したまま、ListViewItemの標準選択色だけが行全幅へ伸びる不整合を解消できたか確認する。

RC19のアプリケーションロジック変更は **List表示の実現済みListViewItem visual clipのみ**。Grid navigation、selection engine、rubber-band、D&D、RC17 keyboard navigationには触れない。

## 0. ビルド・起動

1. `Build.cmd` を実行する。
2. `Portable\Ferry.exe` を起動する。
3. Window title が **Ferry - RC 19** であること。
4. About / version 表示がある場合は `1.1.0-rc19` を確認する。

## 1. 最重要 — List選択色の横幅

列が画面右端まで届かず、右側に十分な余白が残るフォルダをList表示する。

1. 任意の1行 A をクリックする。
2. Aの **青い選択色** が、左10px gutterには入らず、Name列開始位置から **最右の表示カラム右端まで** で止まること。
3. Ferryの破線Selection Anchorと青い選択色の左右端が概ね同じ範囲になること。
4. 最右カラムより右側はAと同じ高さでも白いtrue backgroundのままであること。
5. 別の行でも同じことを確認する。

期待: **破線だけでなく選択色もデータカラム幅に一致**。ListView右端まで青く伸びない。

## 2. 複数選択の選択色

1. Aをクリック → `Shift+↓` を2回。
2. 3行分の青い選択色がすべて最右カラム右端で止まること。
3. `Ctrl+Click` で離れた行を追加し、その行も同じ幅になること。
4. rubber-bandで複数行を選択し、全選択行の色幅が同じであること。

## 3. RC18 true-background回帰

1. Aを選択 → Aと同じ高さの **最右カラムより右側** を単クリック → 0件選択。
2. Aを選択 → 同じ高さの **左10px gutter** を単クリック → 0件選択。
3. 右側true backgroundをダブルクリックしてもAが開かない。
4. 左gutterをダブルクリックしてもAが開かない。

## 4. RC18 rubber-band回帰

1. 最右カラムより右側から左へdrag → rubber-band開始。
2. 左gutterから右へdrag → rubber-band開始。
3. 矩形がデータカラム部分に交差した行だけが選択される。
4. Normal / Ctrl XOR / Shift UNION を最低1回ずつ確認する。

## 5. 列幅変更・表示列変更

1. NameまたはTypeカラムを大きく広げる。
2. 選択色・破線・右側true-background境界が新しい最右カラム位置へ追随する。
3. カラムを狭くする場合も同様。
4. Settings等から列表示/非表示を変更できる場合、変更後も同様。

## 6. 横スクロール

列幅を広げ、Listに水平スクロールが発生する状態を作る。

1. 水平スクロール前に選択行のアイコン・文字・選択色が正常。
2. 右へ水平スクロールする。
3. 右側のカラム内容が欠けたり、突然空白になったりしない。
4. 選択色が表示中のデータ行に自然に追随する。
5. 左へ戻しても正常。

ここはRC19がListViewItemのvisual clipを使うため、必須確認。

## 7. RC17/RC18 keyboard回帰

List:
- Aクリック → 空白 → `↓` = B。
- Aクリック → 空白 → `Shift+↓` = A/B。
- 通常Arrow移動時、選択色と破線が同じ現在行へ追随。

Grid:
- ← → ↑ ↓ が従来どおり。
- 空白解除後の4方向Arrowが従来どおり。

## 8. D&D / rename 最小回帰

1. 選択済み行のデータカラム部分からdrag → file D&Dになる。
2. 右側true backgroundからdrag → file D&Dではなくrubber-bandになる。
3. inline renameを1回開始・確定し、編集欄がクリップで欠けない。

## PASS条件

- 1〜8がすべてOK。
- 特に **青い選択色がList全幅へ伸びない**。
- 横スクロール時にデータ内容が欠けない。

NGが1つでもあればRC19はHOLD。スクリーンショットまたは動画を添付する。
