# Ferry v1.1.0 RC8 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc8`  
**Baseline:** v1.1.0 RC7

## Scope

RC8はRC7の8px Breadcrumb scrollbarに対する**左右end-buttonのvisual chromeのみ**を対象とする。
Windows/.NET Framework 4.8 runtime/compilerはこの環境にないため、実描画・操作はWindows checklistで確認する。

## Source inspection

RC7→RC8のapplication差分を確認。

### `Source/Ferry/MainWindow.cs`

- Window titleを`Ferry - RC 8`へ更新。
- Breadcrumb `ScrollViewer.Loaded`で、配下のhorizontal `ScrollBar`を探索。
- `LineLeftCommand` / `LineRightCommand`を持つline-scroll用`RepeatButton`だけ専用templateへ置換。
- 専用template:
  - normal `#B8B8B8`
  - hover `#A2A2A2`
  - pressed `#8E8E8E`
  - glyph `#626262`
  - button `Opacity=1`, `Visibility=Visible`
- PageLeft/PageRightのtrack用RepeatButtonはcommand判定により対象外。
- Breadcrumb以外のscrollbarはBreadcrumb `ScrollViewer` subtree外なので対象外。
- RC7の8px scrollbar高さと30×30 toolbar sizingは変更なし。
- Rubber-band / selection / keyboard navigation / autoscroll / List↔Grid sync logicは変更なし。

## Build limitation

このLinux containerには`msbuild`, `dotnet`, `csc`, `mcs`が存在せず、.NET Framework 4.8 WPFのcompile/runtime validationは実施不能。

## Windows validation

`V1.1.0_RC8_TEST_JA.md`を使用し、特に以下を確認する。

1. pointer非hover時から左右end button / arrowが見える。
2. normal / hover / pressedの濃度差。
3. left/right clickおよびholdでscrollできる。
4. RC7の8px bar / square toolbar / fixed heightが維持される。
