## Scope

RC18 changes List geometry/hit testing only:

- 10px Explorer-style left gutter;
- Selection Anchor bounds = visible data columns only;
- right-of-columns row tail = true background;
- rubber-band intersection = same data-column span;
- pointer-based item lookup routes use the same bounds.

RC17 Grid keyboard logic is retained unchanged.
