# Ferry v1.1.0 RC6 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc6`  
**Baseline:** v1.1.0 RC5

## Scope

RC6はBreadcrumbのhorizontal scrollbar復帰と、Scrollbar込み固定高さの調整のみを修正対象とする。Windows/.NET Framework 4.8 runtimeはこの環境にないため、実レイアウトはWindows checklistで確認する。

## Root cause / requirement

RC5はRC4のclipping回帰を避けるためBreadcrumbのhorizontal scrollbarを`Hidden`にした。これで文字列は戻ったが、ユーザー要望としてBreadcrumbのhorizontal scrollbar自体も表示しておきたい。

Location Box高さだけに`pathHost`を固定したままScrollbarを復活させるとRC4と同じclippingが再発するため、固定高さ側をScrollbar分だけ拡張する。

## Source diff against RC5

Application source差分は以下のみ。

- `Source/Ferry/MainWindow.cs`
- `Source/Ferry/AssemblyInfo.cs`（version metadataのみ）

Portable release scriptはpackage labelのみ`1.1.0-rc6`へ更新。

## Checks

### Version

- Window title: `Ferry - RC 6`.
- `AssemblyVersion` / `AssemblyFileVersion`: `1.1.0.0` unchanged.
- `AssemblyInformationalVersion`: `1.1.0-rc6`.
- portable release script: `1.1.0-rc6`.

### Breadcrumb fixed-height layout

- Breadcrumb `ScrollViewer.HorizontalScrollBarVisibility`: `Hidden` → `Auto`.
- Location Box remains `Visibility.Hidden` while Breadcrumb is shown, so its desired height remains measurable.
- `pathHost` fixed height = `locationBox.DesiredSize.Height + SystemParameters.HorizontalScrollBarHeight`.
- The additional reserved row prevents a visible horizontal scrollbar from consuming the Location Box-equivalent crumb content height.
- `ScrollBreadcrumbToCurrent()` remains unchanged and continues to call `ScrollToRightEnd()` after Breadcrumb rebuild.

### Unchanged behavior

No intentional changes to Location Box dismissal/focus restoration, Selection Anchor, rubber-band state machine, autoscroll calculation/settings, Sidebar auto-fit, D&D routing, List/Grid selection sync, sorting, ZIP subsystem, or file operations.

- RC5→RC6 application-source diff checked to be limited to Breadcrumb scrollbar/fixed-height handling plus version metadata.
