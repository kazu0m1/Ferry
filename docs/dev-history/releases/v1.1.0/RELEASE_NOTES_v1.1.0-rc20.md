# Ferry v1.1.0 RC20

RC20 is a visual-polish-only candidate following the RC19 real-machine pass.

## Fixed
- The 10px left true-background gutter header now uses the same Windows/WPF theme background as the normal List column headers instead of a separately forced control brush.

## Unchanged
- RC19 selection fill clipping to the data-column span.
- Left/right true-background geometry.
- Rubber-band selection, D&D, List/Grid keyboard navigation, autoscroll, Breadcrumb and settings behavior.

If RC20 passes the short real-machine checklist, it becomes the frozen behavioral/UI baseline for v1.1.0 final.
