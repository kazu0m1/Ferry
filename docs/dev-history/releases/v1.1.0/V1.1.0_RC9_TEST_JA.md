# Ferry v1.1.0 RC9 — 実機確認項目

**基準:** v1.1.0 RC8  
**目的:** Breadcrumb scrollbarを10px化し、thumb / 左右buttonの軽い角丸と操作性を確認する。

---

## A. 10px scrollbar（最重要）

1. 深いpathへ移動するかWindow幅を狭くし、Breadcrumb horizontal scrollbarを表示する。

期待:
- [ ] scrollbar全体がRC8より少し太く、約10pxに見える。
- [ ] thumbがRC8より掴みやすい。
- [ ] thumb dragで左右scrollできる。
- [ ] path文字列が縦方向に欠けない。
- [ ] Toolbar全体が不自然に縦長にならない。

## B. 角丸

- [ ] scrollbar thumbの四隅が軽く丸く見える。
- [ ] 左右end buttonの四隅も軽く丸く見える。
- [ ] 角丸が強すぎず、Windows UIから浮いて見えない。
- [ ] thumb / button間の境界やtrackに不自然な隙間・欠けがない。

## C. RC8 end button維持

- [ ] pointer非hover時から左右button / arrowが常時見える。
- [ ] buttonはthumbより一段濃く見える。
- [ ] hoverで少し濃くなる。
- [ ] pressedでさらに濃くなる。
- [ ] click / holdで左右へ正常にscrollする。

## D. 最小回帰

- [ ] Back / Forward / Up / Home / New tab等は30×30の正方形のまま。
- [ ] `Ctrl+L` ⇄ BreadcrumbでToolbar高さが変わらない。
- [ ] `Ctrl+L` → `Esc`が正常。
- [ ] List/Grid通常rubber-bandが正常。
- [ ] SettingsのRubber-band autoscroll speedは30〜300。
