## RC13実機証拠

ユーザー実機で以下を確認済み。

- selection 0件 / Selector本体focusの状態で、先頭itemをkeyboard originとして`Down`。
- Ferry補正によりindex 0 → index 1へ移動し、target itemへselection / focus / WPF action stateが同期。
- 続く`Down`は通常WPF navigationでindex 2 → 3 → 4...と1件ずつ進行。
- 逆方向も末尾index 78 → `Up` → index 77をFerryが補正し、その後76 → 75...と通常WPF navigationへ復帰。

したがってRC13の補正ロジックは対象経路で実機PASS。
