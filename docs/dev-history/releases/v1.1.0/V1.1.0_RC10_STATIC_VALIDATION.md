# Ferry v1.1.0 RC10 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc10`  
**Baseline:** v1.1.0 RC9

## Scope

RC10はRC9のBreadcrumb scrollbarに対する**corner radius強化（2px → 5px）**のみを対象とする。
Windows/.NET Framework 4.8 runtime/compilerはこの環境にないため、実描画・操作はWindows checklistで確認する。

## Source inspection

RC9→RC10のapplication差分を確認。

### `Source/Ferry/MainWindow.cs`

- Window titleを`Ferry - RC 10`へ更新。
- Breadcrumb horizontal scrollbarのHeight / MinHeight / MaxHeightは**10.0のまま維持**。
- fixed path-host reserveも**10.0のまま維持**。
- Breadcrumb horizontal scrollbar配下の`Thumb`専用templateのCornerRadiusを**2.0 → 5.0**へ変更。
- RC9のline-scroll用`RepeatButton`専用templateのCornerRadiusを**2.0 → 5.0**へ変更。
- RC9の常時表示、normal / hover / pressed color、arrow glyphは維持。
- Breadcrumb外のList/Grid scrollbarは対象外。
- Rubber-band / selection / keyboard navigation / autoscroll / List↔Grid sync logicは変更なし。

### Version metadata

- Window title: `Ferry - RC 10`
- `AssemblyVersion`: `1.1.0.0`
- `AssemblyFileVersion`: `1.1.0.0`
- `AssemblyInformationalVersion`: `1.1.0-rc10`
- portable release script: `1.1.0-rc10`

## Static checks

- Breadcrumb scrollbar size constantsは10.0で一致。
- Thumb / line button templateはいずれもCornerRadius 5.0。
- RC9以前のhistorical release notes / manifestsは履歴として変更しない。

## Build limitation

このLinux containerには.NET Framework 4.8 WPFのWindows build/runtime環境がないためcompile/runtime validationは実施不能。

## Windows validation

`V1.1.0_RC10_TEST_JA.md`を使用し、特に以下を確認する。

1. 10pxでthumbが引き続き掴みやすいか。
2. thumb / end buttonの5px角丸が楕円寄りで好ましいか。
3. end button常時表示と操作が維持されるか。
4. path文字列とToolbar高さが崩れないか。
