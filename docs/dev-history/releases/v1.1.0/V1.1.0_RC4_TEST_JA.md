# Ferry v1.1.0 RC4 — 実機確認項目

**基準:** v1.1.0 RC3 Windows PASS  
**目的:** Breadcrumb / Location Box切替時のtoolbar高さ固定だけを重点確認する。全回帰のやり直しは不要。

---

## A. 最重要 — toolbar高さ固定

1. 通常のBreadcrumb表示状態でtoolbar全体の高さを見る。
2. `Ctrl+L`でLocation Boxへ切り替える。
3. `Esc`でBreadcrumbへ戻る。
4. `Ctrl+L` → `Ctrl+L`再押下でも往復する。

期待:
- [ ] Breadcrumb → Location Boxでtoolbarの高さが変わらない。
- [ ] Location Box → Breadcrumbでtoolbarの高さが変わらない。
- [ ] 連続で何度切り替えても上下にガクつかない。
- [ ] Window幅を変えた後でも同じ。

## B. 長いBreadcrumb

階層の深いpath、またはWindow幅を狭めてBreadcrumbのhorizontal scrollbarが必要になる状態を作る。

期待:
- [ ] scrollbarが必要になってもtoolbar自体の高さはLocation Box時と同じ。
- [ ] Breadcrumbの操作（各crumb click）ができる。
- [ ] `Ctrl+L`切替後も高さは変わらない。

## C. RC3最小回帰

- [ ] `Ctrl+L` → List/Grid mouse操作でBreadcrumbへ戻る。
- [ ] `Ctrl+L` → EscでBreadcrumbへ戻る。
- [ ] Selection Anchorのgray `1,1`破線が従来どおり。
- [ ] Rubber-band autoscroll speed設定が30〜300のまま。
- [ ] Sidebar境界double-click auto-fitが正常。
- [ ] List通常rubber-bandが正常。
- [ ] Grid通常rubber-bandが正常。
