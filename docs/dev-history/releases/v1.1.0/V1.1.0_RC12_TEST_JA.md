# Ferry v1.1.0 RC12 Diagnostic — 実機手順

RC12は修正確認ではなく、**1回の再現操作で原因状態を採取する診断版**です。

## 手順

1. `Build.cmd`を実行。
2. `Portable\Ferry.exe`を起動。
3. タイトルが `Ferry - RC 12 diagnostic` であることを確認。
4. 20件以上あり縦スクロール可能なフォルダをList表示で開く。
5. viewportを一番上にする。
6. **一番上のitemを通常クリック**する。
7. **List最下部のtrue background（itemのない完全空白）を通常クリック**する。
8. statusが0件選択になっていることを確認。
9. **`Down`を1回だけ押す。**
10. 末尾へjumpしたか、どのitemへ移動したかを記録。
11. Ferryを終了する。
12. `Portable\Ferry.log`をこのチャットへアップロードする。

## 重要

- RC12ではDebug Logging設定をONにする必要はありません。診断版が強制的にログを出します。
- 最初の再現では`Down`以外のキーを押さないでください。
- できればRC11で再現した同じフォルダを使用してください。
- `Ferry.log`に過去実行の内容がある場合は、テスト前に削除して構いません。RC12起動後に再生成されます。

## 報告してほしいもの

1. `Down`後に末尾へjumpしたか: **YES / NO**
2. `Ferry.log`そのもの

これだけで十分です。
