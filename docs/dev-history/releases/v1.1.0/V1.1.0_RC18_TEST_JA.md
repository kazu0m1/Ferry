# Ferry v1.1.0 RC18 — 実機確認

対象: `1.1.0-rc18`  
目的: **RC17でPASSしたkeyboard navigationを固定したまま、Listのitem geometryをExplorer寄りに整理し、左gutterと右側true backgroundを安全に導入できているか確認する。**

## 0. ビルド・起動

- [ ] `Build.cmd` が成功する。
- [ ] `Portable\Ferry.exe` が起動する。
- [ ] Window title = `Ferry - RC 18`。

## A. 見た目 — 左gutter

1. List表示にする。
2. Name列の左側を見る。

期待:
- [ ] ListView外枠と最初のデータ列の間に、約10pxの細い空白gutterがある。
- [ ] Name / Items / Type ... の列位置が不自然にずれていない。
- [ ] headerと各rowの列位置が縦に揃っている。
- [ ] gutterがGrid表示には出ない。

## B. 最重要 — Selection Anchorの横幅

1. Listで任意の行Aを通常クリック。
2. 破線Selection Anchorの左右端を見る。
3. `Down`でBへ移動し、同じ確認をする。

期待:
- [ ] 破線の左端はListView外枠ではなく、**左gutterの右側＝最左データ列の開始位置**。
- [ ] 破線の右端は**現在表示している最右データ列の右端**。
- [ ] ウィンドウ右側に余白があっても、破線がListView全幅まで伸びない。
- [ ] `Down`後も選択行と破線が同じ行で、横幅も同じdata-column span。

## C. 右側tailがtrue backgroundになる

前提: ListViewを横に十分広くし、最右データ列より右側に余白を作る。

1. Aを通常クリックして1件選択。
2. **Aと同じ高さだが、最右データ列より右側の余白**を通常クリック。

期待:
- [ ] 選択が0件になる。
- [ ] その場所はA行として扱われない。
- [ ] 破線Selection Anchorの表示はFerryの既存仕様どおり維持されてもよいが、選択は0件。

追加:
3. 同じ右側余白をダブルクリック。

期待:
- [ ] 直前のfile/folderが開かない。

## D. 左gutterがtrue backgroundになる

1. Aを通常クリック。
2. Aと同じ高さの**左gutter**を通常クリック。

期待:
- [ ] 選択が0件になる。
- [ ] A行のclickとして扱われない。

追加:
3. 左gutterをダブルクリック。

期待:
- [ ] itemが開かない。

## E. Rubber-band — 右側tail開始

1. 複数itemが見える位置で、最右データ列より右の余白からMouseDown。
2. 左方向へrubber-bandを伸ばして複数行と交差させる。

期待:
- [ ] rubber-bandが開始する。
- [ ] 矩形がdata-column spanへ入ったitemだけが選択される。
- [ ] 右側tail上だけを動かしている間はitemを誤選択しない。
- [ ] MouseUpでbandが消える。

## F. Rubber-band — 左gutter開始

1. 左gutterからMouseDown。
2. 右方向へrubber-bandを伸ばす。

期待:
- [ ] gutterから正常にrubber-bandを開始できる。
- [ ] data-column spanへ矩形が入った行から選択される。
- [ ] gutterそのものをitem扱いしない。

## G. item領域内の既存操作

1. Name / Type / Sizeなど**data-column span内**を通常クリック。
2. 選択済みitemのicon/text hot zoneからdrag。
3. Ctrl+Click / Shift+Clickも1回ずつ。

期待:
- [ ] 通常clickで従来どおり選択。
- [ ] 選択済みitemからのfile D&Dが従来どおり。
- [ ] Ctrl / Shift selectionが従来どおり。
- [ ] 右tail/gutter導入によって通常item操作が鈍くならない。

## H. column resize / hide回帰

1. NameやTypeなどの列幅を変更する。
2. 最右列の右端位置が変わったことを確認する。
3. Columnsメニューで列を1つ非表示→再表示する。

期待:
- [ ] 破線の右端が新しい最右列位置へ追随する。
- [ ] 右側true-backgroundの開始位置も新しい最右列位置へ追随する。
- [ ] 左gutter幅は約10pxのまま。
- [ ] gutterがColumnsメニューに「謎の列」として出現しない。

## I. settings persistence

1. 列順/列幅を任意に変更。
2. Ferryを終了して再起動。

期待:
- [ ] 通常の列順/列幅が保存される。
- [ ] `__FerryListGutter` のような内部名が設定やUIに露出しない。
- [ ] 左gutterは再起動後も先頭に1つだけ存在する。

## J. Search / Recycle Bin 最小確認

- [ ] Search resultsでLocation列が追加されても、破線はLocation列右端までで止まる。
- [ ] Recycle BinでOriginal Location列が追加されても、破線は最右列右端までで止まる。
- [ ] それぞれ最右列より右はtrue backgroundとしてclickできる。

## K. RC17 / RC16 keyboard navigation回帰

List:
- [ ] Aクリック → background clear → `Down` = B。
- [ ] Aクリック → background clear → `Shift+Down` = A/B。
- [ ] 通常`Down`数回で選択行と破線が一致。

Grid:
- [ ] Left / Right / Up / Downが視覚方向へ移動。
- [ ] background clear後の4方向ArrowもRC17どおり。
- [ ] GridのSelection Anchor geometryはRC18で変化していない。

## L. Rubber-band modifier最小回帰

- [ ] List normal rubber-band。
- [ ] List Ctrl rubber-band XOR。
- [ ] List Shift rubber-band。
- [ ] Grid normal rubber-band。
- [ ] 選択済みitem内からの通常dragはfile D&D。

## 判定

A〜IおよびKをすべてPASS必須。J/Lは最小回帰として異常がないことを確認する。
