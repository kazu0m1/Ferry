# Ferry v1.1.0 RC19

RC19 is a narrowly scoped visual follow-up to RC18.

## Fixed
- In Details/List view, the native selected-row fill no longer intentionally extends across the entire ListView width. The realized row visual is clipped to the same data-column span used by Ferry's Selection Anchor and RC18 interaction geometry.
- The 10px left gutter and the area to the right of the final visible data column remain visually clear, matching their true-background interaction behavior.

## Unchanged
- List/Grid keyboard navigation
- Rubber-band Normal/Ctrl/Shift/Ctrl+Shift behavior
- Autoscroll
- D&D
- Column geometry and persistence
