# Ferry v1.1.0 RC8 — 実機確認項目

**基準:** v1.1.0 RC7  
**目的:** 8px Breadcrumb scrollbarの左右移動buttonを常時表示し、発見性と操作性を確認する。

---

## A. 左右移動button（最重要）

1. 深いpathへ移動するかWindow幅を狭くして、Breadcrumb horizontal scrollbarを表示する。
2. scrollbar周辺へmouseを置かない状態で確認する。

期待:
- [ ] scrollbar左端の移動buttonが常時見える。
- [ ] scrollbar右端の移動buttonが常時見える。
- [ ] 左右arrow glyphもhover前から見える。
- [ ] buttonはscrollbar本体より一段濃いgrayに見える。
- [ ] 8px scrollbar全体として主張が強すぎない。

3. 左右buttonへmouseを移動し、click / holdする。

期待:
- [ ] hoverでbuttonが少し濃くなる。
- [ ] pressedでさらに濃くなる。
- [ ] 左buttonでBreadcrumbが左へ移動する。
- [ ] 右buttonでBreadcrumbが右へ移動する。
- [ ] holdした場合も従来どおり連続移動できる。

## B. RC7 layout維持

- [ ] Breadcrumb scrollbarは約8pxのまま。
- [ ] path文字列が縦方向に欠けない。
- [ ] Back / Forward / Up / Home / New tabが30×30の正方形に見える。
- [ ] List / Grid / Settingsも正方形に見える。
- [ ] `Ctrl+L` ⇄ BreadcrumbでToolbar高さが変わらない。

## C. 最小回帰

- [ ] 長いBreadcrumbをthumb dragで左右scrollできる。
- [ ] `Ctrl+L` → `Esc`が正常。
- [ ] `Ctrl+L` → file view mouse操作でBreadcrumbへ戻る。
- [ ] List/Grid通常rubber-bandが正常。
- [ ] SettingsのRubber-band autoscroll speedは30〜300。
