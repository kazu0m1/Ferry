# Ferry v1.1.0 RC5 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc5`  
**Baseline:** v1.1.0 RC4

## Scope

RC5はRC4で発生したBreadcrumb表示回帰のみを修正対象とする。Windows/.NET Framework 4.8 runtimeはこの環境にないため、実レイアウトはWindows checklistで確認する。

## Root cause

RC4では`pathHost`をLocation Boxの高さへ固定した一方、Breadcrumb `ScrollViewer`は`HorizontalScrollBarVisibility.Auto`のままだった。

長いBreadcrumb等でhorizontal scrollbarが出ると、そのScrollbar自身が固定されたpathHost内部の高さを消費し、crumb contentの縦表示領域が極端に狭くなる。その結果、Breadcrumb文字列がほぼ/完全に見えなくなる。

## Source diff against RC4

Application source差分は以下のみ。

- `Source/Ferry/MainWindow.cs`
- `Source/Ferry/AssemblyInfo.cs`（version metadataのみ）

Portable release scriptはpackage labelのみ`1.1.0-rc5`へ更新。

## Checks

### Version

- Window title: `Ferry - RC 5`.
- `AssemblyVersion` / `AssemblyFileVersion`: `1.1.0.0` unchanged.
- `AssemblyInformationalVersion`: `1.1.0-rc5`.
- portable release script: `1.1.0-rc5`.

### Breadcrumb fix

- `pathHost`のLocation Box-height固定を維持。
- Breadcrumb `ScrollViewer.HorizontalScrollBarVisibility`: `Auto` → `Hidden`.
- Scrollbarがlayout高さを消費しないため、固定高さ内をcrumb contentが使用できる。
- `BuildBreadcrumb()`後に`ScrollBreadcrumbToCurrent()`を呼び、Dispatcher `Loaded`優先度で`ScrollToRightEnd()`する。
- Recycle Binとdrive rootのearly-return pathでも右端表示処理を呼ぶ。

### Unchanged behavior

No intentional changes to Location Box dismissal/focus restoration, Selection Anchor, rubber-band state machine, autoscroll calculation/settings, Sidebar auto-fit, D&D routing, List/Grid selection sync, sorting, ZIP subsystem, or file operations.

- RC4→RC5 application-source diff checked to be limited to Breadcrumb overflow handling plus version metadata.
