## Intended Source/Ferry diff from RC1

Only these application source files differ:

- `MainWindow.cs`
  - title `Ferry - RC 2`;
  - List/Grid mouse interaction dismisses the visible Location Box with `HideLocationBox(false)`;
  - Selection Anchor stroke changed to dark gray `RGB(112,112,112)` with `StrokeDashArray = {2,3}`;
  - rubber-band autoscroll ceiling reads `settings.RubberBandAutoScrollSpeed`;
  - per-tick guard raised from 3 to 4 so the configured 150 ceiling can be reached without changing the 25 ms timer.
- `AppSettings.cs`
  - adds `RubberBandAutoScrollSpeed`;
  - default 100;
  - older/missing value normalizes to 100;
  - valid persisted range clamped to 30–150.
- `SettingsWindow.cs`
  - adds the Selection section and 30–150 slider;
  - Save / Load / Reset / Import / Export copy paths include the new setting.
- `AssemblyInfo.cs`
  - informational version `1.1.0-rc2`.

All other files under `Source/Ferry` are byte-identical to RC1.
