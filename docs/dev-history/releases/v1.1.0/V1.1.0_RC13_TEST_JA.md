# Ferry v1.1.0 RC13 — 実機確認項目

**基準:** RC12 diagnostic  
**目的:** true-background clear後の`Down`で末尾へjumpする経路を修正できたか確認する。

## A. 元の再現手順（最重要）

1. 20件以上あり縦scroll可能なfolderをList表示で開く。
2. viewportを一番上にする。
3. **一番上のitem Aを通常クリック**する。
4. 必要ならmouse wheel / scrollbarで末尾までscrollする。途中で別itemをクリックしない。
5. **末尾itemより下のtrue backgroundを通常クリック**して0件選択にする。
6. **`Down`を1回だけ押す。**

期待:
- [ ] viewportが末尾へjumpしない。
- [ ] Aをkeyboard navigation originとして、その次のitem（index 1）へ移る。
- [ ] target itemが選択され、keyboard focusもtargetへ入る。
- [ ] そのままさらに`Down`を押すと、次itemへ通常どおり1件ずつ進む。

## B. 一般化確認

1. 画面中央付近の任意item Mをクリック。
2. true backgroundをクリックして0件選択。
3. `Down`。
   - [ ] Mの次itemへ1件だけ進む。
4. 同じ操作をやり直し、最後に`Up`。
   - [ ] Mの前itemへ1件だけ進む。

## C. viewport外origin

1. 先頭itemをクリック。
2. itemをクリックせず末尾までscroll。
3. true backgroundで0件選択。
4. `Down`。

期待:
- [ ] 先頭付近（index 1）へ戻り、末尾itemを選択しない。
- [ ] freeze / 長時間停止がない。

## D. 最小回帰

- [ ] item選択中の通常`Up`/`Down`は従来どおり。
- [ ] `Shift+Up/Down`等のnative keyboard selectionは変更されていない。
- [ ] true background単クリックで0件選択になる。
- [ ] 通常rubber-bandが動作する。
- [ ] Ctrl rubber-band XORが動作する。
- [ ] List⇄Grid切替でselectionが同期する。

## E. 失敗時

RC13は`Ferry.log`を強制出力する。Aで失敗した場合は、

1. Ferryを終了
2. `Portable\Ferry.log`をアップロード

でよい。
