### Selection Anchor

- anchor source remains Ferry's logical `SelectionAnchorItem` overlay.
- stroke remains 1 px dark gray `RGB(112,112,112)` / `#707070`.
- dash rhythm is restored from RC2 `2,3` to Prototype 27 `1,1`.
- no selection/anchor mutation logic was changed for this visual adjustment.

### Rubber-band autoscroll setting

- UI range: 30–300.
- persisted/imported range normalization: 30–300.
- default remains 100.
- Save / Load / Reset / Import / Export path continues to carry `RubberBandAutoScrollSpeed`.
- value 100 preserves the previous base acceleration curve exactly (`speedScale = 1`).
- other values multiply the base curve by `setting / 100`, then clamp at the selected setting.
- per-tick step guard is derived from selected maximum speed; at 300 and 25 ms it permits 8 steps, enough for the 7.5-lines/tick theoretical maximum.

### Sidebar auto-fit

- the existing transparent 5-DIP `GridSplitter` receives a double-click handler.
- single-click/drag resize code path is not replaced.
- auto-fit measures direct Sidebar headings/buttons and Pinned item display names.
- visible vertical scrollbar width is included.
- resulting width is clamped to the existing 50–480 limits.
- the resulting width is assigned to `settings.SidebarWidth` and saved.
- List/Grid mode is irrelevant to the splitter handler, so the same boundary works in either file view.

### Location Box

RC2 Location Box dismissal code is unchanged by RC3.
