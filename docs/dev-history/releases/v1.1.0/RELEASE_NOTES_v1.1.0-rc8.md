# Ferry v1.1.0 RC8

RC8は、RC7で採用した8px Breadcrumb scrollbarの**左右移動buttonの発見性**だけを改善するUI仕上げ候補です。

## 変更点

- Breadcrumb horizontal scrollbarの左右端buttonを常時表示。
- 通常時はscrollbar本体より一段濃いgray。
- mouse hover時はさらに濃く、pressed時はもう一段濃く表示。
- 左右矢印glyphも通常時から表示。
- RC7で確定した8px scrollbar高、Toolbar 30×30 square button、Breadcrumb / Location Box固定高さは維持。
- Rubber-band / Selection Anchor / autoscroll / Location Box / Sidebar auto-fit / List↔Grid selection syncには変更なし。

## バージョン

- Window title: `Ferry - RC 8`
- AssemblyVersion/FileVersion: `1.1.0.0`
- InformationalVersion: `1.1.0-rc8`

Windows実機では `V1.1.0_RC8_TEST_JA.md` の局所確認を行ってください。
