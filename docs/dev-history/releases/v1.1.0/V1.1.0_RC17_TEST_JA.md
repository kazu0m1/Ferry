# Ferry v1.1.0 RC17 — 実機確認

対象: `1.1.0-rc17`  
目的: **RC16でPASSしたListを固定したまま、Gridの4方向keyboard navigationを修正できているか確認する。**

## 0. ビルド・起動

- [ ] `Build.cmd` が成功する。
- [ ] `Portable\Ferry.exe` が起動する。
- [ ] Window title = `Ferry - RC 17`。

## A. 最重要 — Grid / 通常RightでSelection Anchorが追随する

1. Grid表示にする。
2. 左上tile Aを通常クリック。
3. `Right`を1回。
4. さらに`Right`を2〜3回。

期待:
- [ ] 選択は視覚的に右隣へ1tileずつ移動する。
- [ ] 破線Selection Anchorは**毎回、青い選択tileと同じtile**へ即座に移動する。
- [ ] 1tile遅れて追随しない。

## B. Grid / background clear → Right

1. 左上tile Aを通常クリック。
2. Gridの完全空白を通常クリックし0件選択にする。
3. `Right`を1回。

期待:
- [ ] Aの右隣tile Bが選択される。
- [ ] focus / Selection AnchorもBに一致する。
- [ ] 何も起きない、端へjumpする、Aのままになる、はいずれもNG。

## C. Grid / background clear → Down（最重要）

1. 左上tile Aを通常クリック。
2. 完全空白をクリックし0件選択。
3. `Down`を1回。

期待:
- [ ] **Aの真下のtile**が選択される。
- [ ] List順で単に「2番目」を選ばない。
- [ ] 破線も同じtileへ移る。

## D. Grid / Up / Left

- [ ] 中央付近tileをクリック → background clear → `Left` = 左隣。
- [ ] 中央付近tileをクリック → background clear → `Up` = 真上。
- [ ] selection / focus / 破線が同じtileになる。

## E. Grid / Shift + Arrow after background clear

1. 左上Aをクリック → background clear。
2. `Shift+Right`。

期待:
- [ ] Aと右隣Bが選択される。

別試験:
1. 左上Aをクリック → background clear。
2. `Shift+Down`。

期待:
- [ ] Aから真下tileまで、Gridのitem order上の連続範囲が選択される。
- [ ] viewport端へjumpしない。

## F. Grid / native navigation回帰

選択が残っている通常状態で:
- [ ] `Left / Right / Up / Down` が従来どおり視覚方向へ移動する。
- [ ] 無修飾Arrow後、破線が選択tileと一致する。
- [ ] その後 `Shift+Arrow` を開始すると、現在tileを起点に範囲が伸びる。

## G. List — RC16固定回帰

RC17ではListロジックを変えていないが、最小確認する。

- [ ] Aクリック → background clear → `Down` = B。
- [ ] Aクリック → background clear → `Shift+Down` = A/B。
- [ ] 通常`Down`を数回 → 青い選択行と破線が常に一致。
- [ ] 末尾 → background clear → `Up`も1行ずつ戻る。

## H. Rubber-band最小回帰

- [ ] List: true backgroundから通常rubber-band。
- [ ] Grid: true backgroundから通常rubber-band。
- [ ] Ctrl rubber-band XORが成立。
- [ ] 選択済みitemから通常dragするとfile D&Dでありrubber-bandにならない。

## 判定

A〜GがすべてPASSなら、RC17のGrid keyboard navigation修正はPASS。
Hは最小回帰として異常がないことを確認する。
