# Ferry v1.1.0 RC6 — 実機確認項目

**基準:** v1.1.0 RC5
**目的:** Breadcrumbのhorizontal scrollbarを復活させつつ、Scrollbar込みの固定高さでpath文字列を正常表示することを確認する。

---

## A. 通常Breadcrumb

1. Ferryを通常幅で起動する。
2. 数段のfolder階層へ移動する。
3. `Ctrl+L` → Location Box → `Esc`でBreadcrumbへ戻す。
4. 数回切り替える。

期待:
- [ ] Breadcrumbのcrumb/button文字列が正常に見える。
- [ ] Location Box表示時とBreadcrumb表示時でtoolbar/path領域の高さが変わらない。
- [ ] `Ctrl+L` → `Esc`後もBreadcrumbが正常に再表示される。
- [ ] crumb clickで親階層へ移動できる。

## B. 長いpath / 狭いWindow

1. Windowを狭くするか、深いpathへ移動する。
2. Breadcrumb幅を超える状態を作る。

期待:
- [ ] horizontal scrollbarが表示される。
- [ ] scrollbar表示中でもBreadcrumb文字列が縦方向に欠けない／消えない。
- [ ] path hostの固定高さは変わらない。
- [ ] 現在位置側（右端側）のcrumbが初期表示される。
- [ ] scrollbarを左右へ操作して隠れたcrumbを確認できる。

## C. RC3〜RC5最小回帰

- [ ] `Ctrl+L` → List/Grid mouse操作でBreadcrumbへ戻る。
- [ ] Selection Anchorはgray `1,1`破線。
- [ ] Rubber-band autoscroll speed設定は30〜300。
- [ ] Sidebar境界double-click auto-fitが正常。
- [ ] List/Grid通常rubber-bandが正常。
