# Ferry v1.1.0 RC9 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc9`  
**Baseline:** v1.1.0 RC8

## Scope

RC9はRC8のBreadcrumb scrollbarに対する**10px化 + thumb / end-button corner radius**のみを対象とする。
Windows/.NET Framework 4.8 runtime/compilerはこの環境にないため、実描画・操作はWindows checklistで確認する。

## Source inspection

RC8→RC9のapplication差分を確認。

### `Source/Ferry/MainWindow.cs`

- Window titleを`Ferry - RC 9`へ更新。
- Breadcrumb horizontal `ScrollBar`のHeight / MinHeight / MaxHeightを8.0 → **10.0**へ変更。
- fixed path-host reserveを8.0 → **10.0**へ変更。
- Breadcrumb horizontal scrollbar配下の`Thumb`だけを探索し、専用templateへ置換。
- Thumb template:
  - normal `#C8C8C8`
  - hover `#B8B8B8`
  - dragging `#A8A8A8`
  - CornerRadius `2.0`
- RC8のline-scroll用`RepeatButton`専用templateへCornerRadius `2.0`を追加。
- RC8の常時表示、normal / hover / pressed color、arrow glyphは維持。
- Breadcrumb外のList/Grid scrollbarは対象外。
- Rubber-band / selection / keyboard navigation / autoscroll / List↔Grid sync logicは変更なし。

### Version metadata

- Window title: `Ferry - RC 9`
- `AssemblyVersion`: `1.1.0.0`
- `AssemblyFileVersion`: `1.1.0.0`

## Static checks

- Breadcrumb scrollbar size constantsは10.0で一致。
- Thumb / line button templateはいずれもCornerRadius 2.0。
- RC8以外のhistorical release notes / manifestsは履歴として変更しない。

## Build limitation

このLinux containerには.NET Framework 4.8 WPFのWindows build/runtime環境がないためcompile/runtime validationは実施不能。

## Windows validation

`V1.1.0_RC9_TEST_JA.md`を使用し、特に以下を確認する。

1. 10pxでthumbが掴みやすくなったか。
2. thumb / end buttonの2px角丸が自然か。
3. end button常時表示と操作が維持されるか。
4. path文字列とToolbar高さが崩れないか。
