# Ferry v1.1.0 RC10 — 実機確認項目

**基準:** v1.1.0 RC9  
**目的:** Breadcrumb scrollbarの10px高さは維持したまま、thumb / 左右buttonの角丸をより強くして楕円寄りに見えるか確認する。

---

## A. 10px scrollbar（維持確認）

1. 深いpathへ移動するかWindow幅を狭くし、Breadcrumb horizontal scrollbarを表示する。

期待:
- [ ] scrollbar全体が約10pxに見える。
- [ ] thumbが十分掴みやすい。
- [ ] thumb dragで左右scrollできる。
- [ ] path文字列が縦方向に欠けない。
- [ ] Toolbar全体が不自然に縦長にならない。

## B. 強めの角丸（最重要）

- [ ] scrollbar thumbの四隅がRC9より明確に丸く、楕円寄りに見える。
- [ ] 左右end buttonの四隅もRC9より明確に丸く見える。
- [ ] thumb / buttonが卵型っぽく見えても、安っぽくは見えない。
- [ ] 角丸が強くなってもtrackや周囲との境界が不自然に崩れない。
- [ ] thumb / button間に欠けや白い隙間がない。

## C. RC9仕様維持

- [ ] pointer非hover時から左右button / arrowが常時見える。
- [ ] buttonはthumbより一段濃く見える。
- [ ] hoverで少し濃くなる。
- [ ] pressedでさらに濃くなる。
- [ ] click / holdで左右へ正常にscrollする。

## D. 最小回帰

- [ ] Back / Forward / Up / Home / New tab等は30×30の正方形のまま。
- [ ] `Ctrl+L` ⇄ BreadcrumbでToolbar高さが変わらない。
- [ ] `Ctrl+L` → `Esc`が正常。
- [ ] List/Grid通常rubber-bandが正常。
- [ ] SettingsのRubber-band autoscroll speedは30〜300。
