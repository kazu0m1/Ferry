# Ferry v1.1.0 RC7 — 実機確認項目

**基準:** v1.1.0 RC6  
**目的:** 8px Breadcrumb scrollbar案とToolbar正方形buttonの実機見た目を確認する。

---

## A. Toolbar外観（最重要）

1. Ferryを通常幅で起動する。
2. Breadcrumb表示状態を見る。

期待:
- [ ] Back / Forward / Up / Home / New tabが正方形に見える。
- [ ] List / Grid / Settings icon buttonも正方形に見える。
- [ ] `Columns`、Search mode、Search boxとの縦位置が揃っている。
- [ ] RC6のようにbutton類が縦に伸びて不格好に見えない。

## B. Breadcrumb 8px scrollbar

1. 深いpathへ移動するかWindowを狭くし、Breadcrumb横幅を超える状態を作る。

期待:
- [ ] horizontal scrollbarが表示される。
- [ ] scrollbarがWindows標準より明確に細く、概ね8px相当に見える。
- [ ] thumbをmouseでdragして左右へ移動できる。
- [ ] scrollbar表示中でもBreadcrumb文字列が縦方向に欠けない／消えない。
- [ ] 現在位置側（右端側）が初期表示される。

## C. Location Boxとの高さ固定

1. `Ctrl+L` → Location Box。
2. `Esc` → Breadcrumb。
3. 数回往復する。

期待:
- [ ] Toolbar全体の高さが切替のたびに変化しない。
- [ ] Location Box文字列が上下に欠けない。
- [ ] Breadcrumbへ戻った後もpathが正常表示される。

## D. 最小回帰

- [ ] `Ctrl+L` → List/Grid mouse操作でBreadcrumbへ戻る。
- [ ] Selection Anchorはgray `1,1`破線。
- [ ] Rubber-band autoscroll speed設定は30〜300。
- [ ] Sidebar境界double-click auto-fitが正常。
- [ ] List/Grid通常rubber-bandが正常。
