# Ferry v1.1.0 RC10

RC10は、RC9で10px化したBreadcrumb horizontal scrollbarの**角丸量だけ**を再調整する局所UI候補です。

## 変更点

- Breadcrumb scrollbar thumbのcorner radiusを**2px → 5px**へ拡大。
- 左右end buttonのcorner radiusも**2px → 5px**へ拡大。
- 10px高、thumb / buttonのgray系配色、end button常時表示、arrow常時表示は維持。
- Breadcrumb / Location Box固定高さは30px + 10px scrollbar分のまま。
- Toolbar 30×30 square button、Location Box、rubber-band / Selection Anchor / autoscroll / Sidebar auto-fit / List↔Grid syncには変更なし。

## バージョン

- Window title: `Ferry - RC 10`
- AssemblyVersion/FileVersion: `1.1.0.0`
- InformationalVersion: `1.1.0-rc10`

Windows実機では `V1.1.0_RC10_TEST_JA.md` の局所確認を行ってください。
