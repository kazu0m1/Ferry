## Functional change

Ctrl+L Location Box now has one explicit show/hide state path:

- First `Ctrl+L`: Breadcrumb -> Location Box.
- `Esc` while Location Box is visible: Location Box -> Breadcrumb.
- Second `Ctrl+L` while Location Box is visible: Location Box -> Breadcrumb.
- Returning from Location Box restores the exact keyboard-focused element that was active before Ctrl+L when possible.
- If that element no longer exists, Ferry falls back to the active List/Grid selector.
- Esc while Location Box is visible is intercepted before Ferry's ordinary Esc selection/search route, so it does not accidentally clear the current file selection.
- Enter with a valid directory keeps the existing navigation path; invalid directories keep the editor open.
