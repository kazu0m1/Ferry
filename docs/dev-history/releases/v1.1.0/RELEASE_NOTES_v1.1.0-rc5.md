# Ferry v1.1.0 RC5

RC5 is a focused UI regression fix on top of RC4.

## Fixed

- Fixed Breadcrumb text becoming clipped/invisible after RC4 fixed the path area to the Location Box height.
- Breadcrumb horizontal overflow no longer reserves a scrollbar row inside the fixed-height toolbar.
- Long Breadcrumbs automatically keep the current-location side visible.

## Unchanged from RC3/RC4

- Explorer-style rubber-band selection and modifier behavior.
- Selection Anchor visualization.
- Configurable rubber-band autoscroll speed (30–300).
- Sidebar divider double-click auto-fit.
- Ctrl+L Location Box dismissal/return behavior.
