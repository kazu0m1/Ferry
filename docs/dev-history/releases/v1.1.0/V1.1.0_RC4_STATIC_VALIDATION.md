# Ferry v1.1.0 RC4 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc4`  
**Baseline:** v1.1.0 RC3 (Windows PASS)

## Scope

RC4はBreadcrumb / Location Box切替時のtoolbar高さ固定だけをapplication変更対象とする。Windows/.NET Framework 4.8 runtimeはこの環境にないため、実レイアウトはWindows checklistで確認する。

## Source diff against RC3

Application source差分は以下のみ。

- `Source/Ferry/MainWindow.cs`
- `Source/Ferry/AssemblyInfo.cs`（version metadataのみ）

Portable release scriptはpackage labelのみ`1.1.0-rc4`へ更新。

## Checks

### Version

- Window title: `Ferry - RC 4`.
- `AssemblyVersion` / `AssemblyFileVersion`: `1.1.0.0` unchanged.
- `AssemblyInformationalVersion`: `1.1.0-rc4`.
- portable release script: `1.1.0-rc4`.

### Toolbar height fix

- `locationBox` initial/hidden state is `Visibility.Hidden`, not `Collapsed`; therefore it remains in WPF layout while not rendered or hit-testable.
- `HideLocationBox()` returns it to `Hidden`.
- `ShowLocationBox()` still changes it to `Visible`; Location Box behavior itself is unchanged.
- `pathHost.Loaded` reads `locationBox.DesiredSize.Height` and applies the same value to `Height`, `MinHeight`, and `MaxHeight`.
- Breadcrumb `ScrollViewer` remains within this fixed path-host height, preventing its horizontal scrollbar from increasing toolbar height.

### Unchanged RC3 behavior

No intentional changes to Selection Anchor visual/logic, autoscroll speed, Sidebar auto-fit, Location Box dismissal rules, rubber-band state machine, D&D routing, List/Grid selection sync, sorting, ZIP subsystem, or file operations.

## Mechanical sanity checks

- MainWindow raw brace balance checked.
- RC4 title/version strings checked.
- RC3→RC4 application-source diff checked to be limited to the toolbar layout block, `HideLocationBox` hidden state, and version metadata.
