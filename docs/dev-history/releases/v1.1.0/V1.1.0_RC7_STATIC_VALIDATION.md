# Ferry v1.1.0 RC7 — Static Validation

**Date:** 2026-09-15  
**Candidate:** `1.1.0-rc7`  
**Baseline:** v1.1.0 RC6

## Scope

RC7はToolbar/BreadcrumbのUI sizingのみを対象とする。Windows/.NET Framework 4.8 runtime/compilerはこの環境にないため、実レイアウトはWindows checklistで確認する。

## Source diff against RC6

Application source差分は以下のみ。

- `Source/Ferry/MainWindow.cs`
- `Source/Ferry/AssemblyInfo.cs`（version metadataのみ）

Portable release scriptはpackage labelのみ`1.1.0-rc7`へ更新。

## Checks

### Version

- Window title: `Ferry - RC 7`.
- `AssemblyVersion` / `AssemblyFileVersion`: `1.1.0.0` unchanged.
- `AssemblyInformationalVersion`: `1.1.0-rc7`.
- portable release script: `1.1.0-rc7`.

### Breadcrumb scrollbar

- Breadcrumb `HorizontalScrollBarVisibility = Auto`を維持。
- Breadcrumb `ScrollViewer.Resources`にlocal `Style(typeof(ScrollBar))`を設定。
- Horizontal orientationだけHeight / MinHeight / MaxHeight = `8.0`。
- StyleはBreadcrumb ScrollViewer subtreeに限定され、List/Grid等のScrollbar sizingは変更しない。
- Breadcrumb再構築後の`ScrollToRightEnd()`は変更なし。

### Toolbar sizing

- Common `ToolbarButton` height = 30。
- Icon buttonは`MakeSquareToolbarButton()`により30×30。
- `Columns`は内容幅を維持。
- Search mode / Search box / Location Box height = 30。
- `pathHost` fixed height = Location Box height + 8px reserved scrollbar row。

### Unchanged behavior

No intentional changes to Location Box dismissal/focus restoration, Selection Anchor, rubber-band state machine, autoscroll calculation/settings, Sidebar auto-fit, D&D routing, List/Grid selection sync, sorting, ZIP subsystem, or file operations.

## Mechanical sanity checks

- MainWindow raw brace balance checked.
- RC7 title/version strings checked.
- RC6→RC7 application-source diff checked to be limited to Toolbar/Breadcrumb sizing plus version metadata.
