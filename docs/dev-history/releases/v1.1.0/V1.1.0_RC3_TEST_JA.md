## B. Rubber-band autoscroll speed 30–300

Settingsを開く。

期待:
- [ ] **Rubber-band autoscroll speed (30–300)** が表示される。
- [ ] 初期値/Reset値が100。
- [ ] 30 / 50 / 100 / 200 / 300へ設定できる。
- [ ] Save後、再起動して値が保持される。
- [ ] Export → Importでも値が保持される。

体感確認（できるだけ同じpointer距離で比較）:
- [ ] 50 < 100 < 200 < 300 の速度差が明確に感じられる。
- [ ] 100はRC2以前のdefault体感と同程度。
- [ ] 300でも上下方向にワープ・ちらつき・選択消失がない。
- [ ] pointerを中央へ戻すと即座にautoscrollが止まる。
- [ ] 下方向・上方向とも正常。

## C. Sidebar splitter double-click auto-fit

2. SidebarとList/Gridの境界線（resize cursorになる場所）をdouble-clickする。

期待:
- [ ] Sidebarが表示中の文字列に合う幅へ一度で変わる。
- [ ] Places / Drives / System / Pinnedの長い表示名が不必要に切れない。
- [ ] 長すぎる文字列がある場合でも480を超えて広がらない。
- [ ] vertical scrollbar表示中でも文字列がscrollbarに不自然に隠れない。
- [ ] double-click後も境界をdragして通常どおり手動resizeできる。
- [ ] Ferry再起動後もauto-fitした幅が保持される。
- [ ] Grid viewでも同じ境界double-clickが機能する。

追加確認:
