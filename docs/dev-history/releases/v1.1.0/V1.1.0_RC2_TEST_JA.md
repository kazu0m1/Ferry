# Ferry v1.1.0 RC2 — 実機確認項目

**基準:** v1.1.0 RC1 Windows PASS  
**目的:** RC2で追加した3つのUX仕上げだけを重点確認する。Prototype 27〜RC1で完了済みの全回帰を最初から繰り返す必要はない。

---

## A. Location Box → file view操作でBreadcrumb復帰

1. 任意のitemを選択する。
2. `Ctrl+L`でLocation Boxを表示する。
3. Listの別itemを通常左クリックする。

期待:
- [ ] Location Boxが消え、Breadcrumbへ戻る。
- [ ] クリックしたitemが通常どおり選択される。
- [ ] その後↑/↓キーがクリックitemから正常に続く。
- [ ] Ctrl+L前の古いfocusへ勝手に戻らない。

追加:
- [ ] `Ctrl+L` → List true backgroundクリックでもBreadcrumbへ戻る。
- [ ] `Ctrl+L` → Grid itemクリックでもBreadcrumbへ戻る。
- [ ] `Ctrl+L` → 右クリックでもBreadcrumbへ戻り、通常のcontext menu/selection動作を壊さない。
- [ ] `Ctrl+L` → フォルダを中クリックして新規タブを開く場合もBreadcrumbへ戻る。
- [ ] `Esc`によるBreadcrumb復帰はRC1同様に正常。
- [ ] Location Box表示中の`Ctrl+L`再押下もRC1同様に正常。

## C. Rubber-band autoscroll速度設定

Settingsを開く。

期待:
- [ ] **Rubber-band autoscroll speed (30–150)** が表示される。
- [ ] 初期値/Reset値が **100**。
- [ ] 30 / 100 / 150へ変更してSaveできる。
- [ ] Ferry再起動後も設定値が保持される。
- [ ] Export → Importでも設定値が保持される。

体感確認:
- [ ] 30では100より明確に遅い。
- [ ] 100はPrototype 20〜RC1の既定体感と同程度。
- [ ] 150では100より明確に速い。
- [ ] どの値でもedge直近は急発進せず、外側へ離すほど加速する。
- [ ] pointerを中央へ戻すと停止する。
- [ ] 上下方向ともワープ・ちらつき・選択消失がない。
