# Ferry release-development history

Historical release preparation and validation records are grouped by release line.

- `v1.0.0/` — first-public-release smoke test and publication procedure.
- `v1.0.1/` — v1.0.1 publication procedure.
- `v1.0.2/` — v1.0.2 publication guide, final checklist, audit, and static validation.

These files are retained as development history. Current release documentation lives at the repository root and in the top level of `docs/`.
