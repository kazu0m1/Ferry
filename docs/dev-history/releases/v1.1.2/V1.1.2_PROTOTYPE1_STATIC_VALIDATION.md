## Safety gate
Source deletion requires BOTH:

- `DoDragDrop` final effect contains `Move`; and
- `Performed DropEffect` written back by the drop target contains `Move`.

If either signal is absent, Ferry does not delete source data.

Before cleanup, Ferry checks whether each source path still exists. Already-moved paths are not deleted again.
