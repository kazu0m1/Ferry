## Failure diagnosis
BがNGの場合、SettingsでDebug LoggingをONにしてBを1回だけ再実施し、`Ferry.log`の`External D&D completed:`行を確認する。

- `finalEffect=Move, performedMove=True`なのにsourceが残る → cleanup側の問題。
- `finalEffect=Move, performedMove=False` → Explorer→WPF DataObjectへのShell result受信を追加調査。
- `finalEffect=Copy` → Explorerがdrop自体をCopy判定しているため、Preferred DropEffect等を次prototypeで検討。
