# Ferry v1.1.1 prototype 1 — Paste result feedback

## Explorer観察
Pasteによりdestinationへ現れたトップレベルitemが選択され、処理後も選択状態が残る。これは「今回のPasteで何が追加・更新されたか」を示すoperation-result feedbackとして扱う。

## 実装原則
- Copy/Move本体とcollision UIは従来どおりWindows `SHFileOperation`へ委譲する。
- FerryはPaste開始時だけ、Clipboardのsource path一覧とdestination直下の軽量snapshotを保持する。
- FileSystemWatcher / explicit final refreshでdestinationが差分反映された後、今回のPasteに対応するtop-level `FileItem`を特定して選択する。
- 新規path、更新されたexpected destination path、同一folder Copy/Keep-bothで生成されたrenamed siblingを対象にする。
- List/Grid両Selectorへ同一selection setを反映し、最初の結果itemを論理Selection Anchor / keyboard originとする。
- `SHFileOperation`完了後のfinal refreshでsessionを破棄し、後日の無関係refreshで古いPaste selectionを復活させない。

## 非目標
- custom copy engine / queue / graph
- Paste完了toastやmodal success dialog
- 子孫fileまでの再帰的selection（selection対象はdestination直下のトップレベルitem）
