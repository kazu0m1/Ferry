## Candidate scope

Ferry restores useful context when Back navigation returns from a directly opened child folder to its parent, and adds a lightweight New Text Document command to the background context menu.

- [x] In a parent folder with many items, open a child folder located low in the list.
- [x] Press **Back** and confirm the child folder is selected and keyboard-focused.
- [x] Confirm the restored child folder is aligned to the top of List view.
- [x] Right-click the file-view background and choose **New Text Document**.
- [x] Confirm an empty `.txt` file is created.
- [x] Confirm the new file immediately enters inline rename.
