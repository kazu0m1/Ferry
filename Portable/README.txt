Ferry v1.2.2 Portable

Ferry is a lightweight Windows 11 file manager inspired by GNOME Files (Nautilus).

This release:
- Copy and Paste one item into its own folder to create a numbered sibling, such as file (1).txt.
- When several items would be duplicated in the same folder, Ferry asks for confirmation (default No).
- The original items remain unchanged. Cut/Paste and copying to a different folder retain the usual Windows Shell behavior.
- Settings can prepare the To-Do tab at startup. To-Do preserves caret/selection across tab switches.
- To-Do/Memo column boundaries remain aligned when the window is narrow or vertically scrollable.

Installation:
- Extract this portable ZIP into a folder of your choice, then run Ferry.exe.
- Settings and To-Do content are saved locally in config\settings.json beside Ferry.exe.
- Keep your existing config\settings.json when upgrading if you want to retain your settings and To-Do entries.
- No installer is required. .NET Framework 4.8 / WPF is used.

Ferry has no telemetry or automatic crash upload.
